# Mr. Manoj Ramlachan Shukla — Personal Portfolio

Premium personal portfolio built with Python, Flask, HTML, CSS and minimal JavaScript.

## Windows setup

1. Install Python from https://www.python.org/downloads/ and enable **Add python.exe to PATH**.
2. Extract this ZIP.
3. Open PowerShell in the extracted folder.
4. Run `py -m venv .venv`
5. Run `\.venv\Scripts\Activate.ps1`
6. Run `python -m pip install --upgrade pip`
7. Run `python -m pip install -r requirements.txt`
8. Run `python app.py`
9. Open `http://127.0.0.1:5000/`
